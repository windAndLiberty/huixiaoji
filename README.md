# Meeting Companion

阅读需求文档，实现「会小纪」Mobile Web App / PWA 交互原型，搭建会议录音、会中转写与便签双页的核心体验。

包含：
1. 首页工作台：支持开始会议（现场会议/云会议）、录音时长与状态。
2. 会中悬浮 Logo 入口与会中双页无缝切换（消息对话页展示说话人气泡，笔记便签页快速记录）。
3. 真实麦克风录音控制与模拟实时转写流。
4. 会后说话人标注（点击修改姓名/角色）与客观详细笔记生成预览（严格遵守不出现任何说话人归属语句的客观事实总结原则）。
